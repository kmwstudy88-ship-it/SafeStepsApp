## Likely Next Additions To Check

- Assessment detail: the imported 12-course library currently has lesson titles and lesson content mapped into the app format, but course-level assessment types such as rubrics, budget plans, parenting plans, digital agreements, and network maps are not yet modeled as first-class app objects.
- Delivery metadata: weekly session/app-module delivery details are not shown as structured fields in the current course player.
- Facilitator materials: materials, worker notes, assessment indicators, and detailed homework from the zip were compressed into lesson steps where possible, but the UI does not yet expose them as separate sections.
- Completion evidence: some courses imply uploads or written plans. The app may need evidence capture templates for budget plans, genograms, routines, parenting plans, digital agreements, and village maps.
- Course grouping: the library is currently a flat standalone course list. If needed, add categories/phases such as Foundation, Practical Life Skills, Relationships, Digital Safety, and Community.
